# Nombre del Proyecto

Landing page moderna, responsive y ligera construida con **HTML5**, **CSS3** y **JavaScript** puro (sin frameworks).

![Vista previa](./assets/img/preview.png)

## Demo

🔗 [Ver demo en vivo](https://tu-usuario.github.io/nombre-del-proyecto/)

## Características

- Diseño 100% responsive (móvil, tablet y escritorio)
- Estructura semántica y accesible
- Animaciones suaves con CSS y JavaScript
- Menú de navegación adaptable
- Formulario de contacto con validación
- Optimizada para SEO y rendimiento

## Instalación y uso

1. Clona el repositorio:

   ```bash
   git clone https://github.com/tu-usuario/nombre-del-proyecto.git
   ```

2. Entra en la carpeta:

   ```bash
   cd nombre-del-proyecto
   ```

3. Abre `index.html` en tu navegador, o usa un servidor local (por ejemplo, la extensión **Live Server** de VS Code):

   ```bash
   npx serve .
   ```

## Personalización

- **Colores y tipografías:** edita las variables CSS al inicio de `assets/css/styles.css`.

  ```css
  :root {
    --color-primary: #4f46e5;
    --color-secondary: #06b6d4;
    --font-main: 'Inter', sans-serif;
  }
  ```

- **Contenido:** modifica los textos y secciones en `index.html`.
- **Imágenes:** reemplaza los archivos en `assets/img/`.
